    • Local single-user prototype. Bind to loopback. No authentication or tenant isolation.
    • No automatic writes to GitHub or GitLab. No code is modified.
    • Agent output is untrusted and displayed as text.
    • No certification. Absence of a finding is not proof of compliance or of a fix.
